  • GitHub account (sign up at https://github.com)
  • Git installed on your computer
  • Your UPI Payment System project ready

🎯 STEP 1.1: CREATE GITHUB REPOSITORY

1. Go to https://github.com/new
2. Fill in the form:
   ┌─────────────────────────────────────┐
   │ Repository name: upi-payment-system │
   │ Description: UPI Payment Simulation │
   │ Public ✓ (recommended)              │
   │ Do NOT check "Add README"           │
   │ Do NOT check "Add .gitignore"       │
   │ Do NOT check "Choose a license"     │
   └─────────────────────────────────────┘
3. Click "Create repository"
4. You'll see a page with instructions - COPY THE HTTPS URL
5. Example URL: https://github.com/your-username/upi-payment-system.git

🎯 STEP 1.2: PUSH CODE TO GITHUB

Open PowerShell or Command Prompt and run:

```powershell
cd c:\Users\jyoti\OneDrive\Desktop\Fin_UPI
```

Then run these commands one by one:

```powershell
# Initialize Git (if not already done)
git init

# Configure Git (first time only)
git config user.email "your-email@gmail.com"
git config user.name "Your Name"

# Add all files
git add .

# Create commit
git commit -m "Initial commit: UPI Payment System"

# Rename branch to main
git branch -M main

# Add remote (replace with your GitHub URL)
git remote add origin https://github.com/YOUR_USERNAME/upi-payment-system.git

# Push to GitHub
git push -u origin main
```

✅ VERIFICATION:

1. Go to https://github.com/YOUR_USERNAME/upi-payment-system
2. You should see all your files
3. Check that .gitignore is included
4. Look for upi_system.db is NOT there

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WHY RENDER?
  ✓ Perfect for full-stack Python apps
  ✓ Free tier available
  ✓ Easy GitHub integration
  ✓ Automatic deployments on push
  ✓ Handles both frontend and backend

🎯 STEP 2.1: CREATE RENDER ACCOUNT

1. Go to https://render.com
2. Click "Get Started" (top right)
3. Choose "Sign up with GitHub" (easier)
4. Click "Authorize render-oss"
5. Complete the sign-up

🎯 STEP 2.2: CREATE WEB SERVICE

1. After login, click "New +" button (top left)
2. Select "Web Service"
3. Click "Connect Repository"
4. Select your upi-payment-system repository
5. Click "Connect"

🎯 STEP 2.3: CONFIGURE SERVICE

On the deployment form, fill in:

┌────────────────────────────────────────────────────┐
│ Name: upi-payment-system                           │
│ Environment: Python 3                              │
│ Region: Choose closest to you (e.g., us-east-1)   │
│ Branch: main                                       │
│ Build Command:                                     │
│   pip install -r requirements.txt                  │
│                                                    │
│ Start Command:                                     │
│   python -m uvicorn app.main:app --host 0.0.0.0  │
│   --port $PORT                                     │
│                                                    │
│ Root Directory: (leave empty)                      │
│                                                    │
│ Plan: Free (Starter) ✓                            │
│                                                    │
│ Auto-Deploy: Yes (selected) ✓                      │
└────────────────────────────────────────────────────┘

🎯 STEP 2.4: ADD ENVIRONMENT VARIABLES

1. Before creating the service, click "Advanced"
2. In "Environment" section, add:
   ┌─────────────────────────────────────┐
   │ DATABASE_URL                        │
   │ sqlite:///./upi_system.db           │
   └─────────────────────────────────────┘
3. Click "Create Web Service"

⏳ WAITING FOR DEPLOYMENT

1. Render will show deployment logs
2. Watch for "Build completed successfully"
3. Then "Deploying app..."
4. Finally "Deploy successful"
5. This takes 5-10 minutes

✅ VERIFICATION

1. Once deployed, you'll see a URL like:
   https://upi-payment-system.onrender.com

2. Click it or paste in browser

3. You should see your UPI Payment System frontend!

4. Test by registering a user and sending payment

5. If it doesn't work, check logs:
   - In Render dashboard
   - Click on your service
   - Go to "Logs" tab
   - Look for errors

🎉 RENDER DEPLOYMENT COMPLETE!

Your live app URL: https://upi-payment-system.onrender.com

1. Go to https://vercel.com
2. Click "Sign Up" and choose "Continue with GitHub"
3. Authorize Vercel
4. Click "New Project"
5. Select your upi-payment-system repository
6. Configure:
   ┌───────────────────────────────────────┐
   │ Framework: Other (or "None")          │
   │ Root Directory: static                │
   │ Build Command: (leave empty)          │
   │ Output Directory: (leave empty)       │
   └───────────────────────────────────────┘
7. Click "Deploy"

🎯 STEP 3.3: UPDATE API URL

1. Edit: static/script.js
2. Find: const API_BASE_URL = 'http://localhost:8000/api';

   const API_BASE_URL = 'https://upi-payment-system.onrender.com/api';
4. Commit and push to GitHub:
   git add static/script.js
   git commit -m "Update API URL for production"
   git push origin main
5. Vercel auto-deploys

🎯 STEP 3.4: ACCESS FRONTEND

Your frontend will be at: https://upi-payment-system.vercel.app

TROUBLESHOOTING

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Issue: "fatal: could not read Username for 'https://github.com'"

✅ Solution:
   1. Generate GitHub Personal Access Token:
      https://github.com/settings/tokens
   2. Create token with "repo" scope
   3. Use token as password when prompted
   OR
   4. Set up SSH: https://docs.github.com/en/authentication/connecting-to-github-with-ssh

❌ Issue: Render deployment fails with "Python not found"

✅ Solution:
   1. Check Render build logs
   2. Ensure requirements.txt is in root directory
   3. Make sure all dependent packages are listed
   4. Try: pip freeze > requirements.txt locally first

❌ Issue: Frontend shows but says "Cannot connect to API"

✅ Solution:
   1. Check that backend URL is correct in script.js
   2. Verify API is running: https://your-app.onrender.com/health
   3. Check browser console (F12) for CORS errors
   4. CORS is already enabled in app/main.py

❌ Issue: "Database locked" error

✅ Solution:
   1. Render uses ephemeral storage
   2. For production, use PostgreSQL instead
   3. Add PostgreSQL in Render dashboard
   4. Update DATABASE_URL environment variable

❌ Issue: Page loads but no styling (CSS not working)

✅ Solution:
   1. Check browser console (F12) for 404 errors
   2. Verify static files are deployed
   3. Hard refresh: Ctrl+Shift+Delete then reload
   4. Check Render logs to see if serving static files
