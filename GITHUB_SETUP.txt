━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  BEFORE YOU START:

You need:
  ✓ GitHub account (free at https://github.com)
  ✓ Git installed (you have this - already initialized!)

If you don't have a GitHub account yet:
  1. Go to https://github.com
  2. Click "Sign up"
  3. Enter email, create password, choose username
  4. Verify email
  5. Come back here and continue

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 STEP 1: CONFIGURE GIT (ONE TIME ONLY)

Run these commands in PowerShell:

  git config --global user.name "Your Name"
  git config --global user.email "your-email@gmail.com"

Replace:
  - "Your Name" with your actual name
  - "your-email@gmail.com" with your email

Example:
  git config --global user.name "John Doe"
  git config --global user.email "john@gmail.com"

✓ DONE! You'll never need to do this again.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 STEP 2: CREATE GITHUB REPOSITORY

1. Go to: https://github.com/new
2. Fill in the form:

   Repository name: upi-payment-system
   Description: UPI Payment Simulation System
   Public: ✓ (check this)
   
3. Do NOT check:
   ☐ Add a README file
   ☐ Add .gitignore
   ☐ Add a license

4. Click "Create repository"

5. You'll see this page with two sections:
   
   Section: "...or push an existing repository from the command line"
   
   Copy the URL that looks like:
   https://github.com/YOUR_USERNAME/upi-payment-system.git

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 STEP 3: STAGE & COMMIT YOUR CODE

In PowerShell, run these commands (you're already in the right directory):

  # Add all files to staging
  git add .

  # Check what will be committed (optional)
  git status

  # Create commit
  git commit -m "Initial commit: UPI Payment System with frontend and backend"

Expected output:
  create mode 100644 .env
  create mode 100644 .githubub/workflows/deploy.yml
  create mode 100644 .gitignore
  ...
  (many files)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 STEP 4: ADD REMOTE & RENAME BRANCH

In PowerShell, run:

  # Rename local branch to main
  git branch -M main

  # Add remote (replace YOUR_USERNAME)
  git remote add origin https://github.com/YOUR_USERNAME/upi-payment-system.git

Replace YOUR_USERNAME with your actual GitHub username

Example:
  git remote add origin https://github.com/jyoti/upi-payment-system.git

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 STEP 5: PUSH TO GITHUB

In PowerShell, run:

  git push -u origin main

First time push will ask for authentication:

  Option A: GitHub Personal Access Token (RECOMMENDED for Windows)
  Option B: GitHub CLI (easier setup)

Follow the prompt to authenticate.

If prompted for password, use Personal Access Token:
  1. Go to https://github.com/settings/tokens
  2. Click "Generate new token (classic)"
  3. Name: "GitHub Desktop"
  4. Select scopes: repo (full control)
  5. Generate token
  6. Copy token
  7. Paste when prompted (it won't show as you type)

TROUBLESHOOTING

Problem: "fatal: could not read Username"
Solution:
  1. Generate token: https://github.com/settings/tokens
  2. Create with "repo" scope
  3. Use token as password

Problem: "error: src refspec main does not match any"
Solution:
  Make sure commit was successful first:
    git status
  Should show "nothing to commit"

Problem: "remote origin already exists"
Solution:
  git remote remove origin
  Then add it again with correct URL

Problem: Repository not showing up on GitHub
Solution:
  1. Go to https://github.com/settings/repositories
  2. Check if repo is there
  3. Try refreshing page
  4. Check you're logged in to correct account
